# Echo logo usage

The identity is a brass and navy pocket compass. It follows the reviewed Hexly material study `2026-09-07-01`, finishing `01`.

## Asset roles

- `logo.png`: exact 2048 × 2048 transparent foreground, free of the backdrop and cast shadow.
- `assets/brand/icon.png`: square presentation for large cards and platforms that apply their own mask.
- `assets/brand/icon-rounded.png`: large README and gallery presentation.
- `assets/brand/background.png`: independent survey bearings field.

Small header/sidebar marks and favicons use the transparent foreground without an extra tile or circular CSS mask. Touch/PWA icons use the opaque square presentation. Source hashes and provenance live in `assets/brand/source.json`.

## Consumers

- README only: this CLI/API repository has no application logo surface or browser metadata
